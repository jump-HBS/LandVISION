# 06 前端页面设计（v1.3）

## 1. 技术栈

```
Vue 3（组合式 API + <script setup>）· Vite 6 · Pinia（parcel/ui 双 store）
Vue Router 4 · Axios（统一拦截器，适配后端错误码格式）
MapLibre GL JS（地图）· ECharts（图表）· Element Plus（UI，支持深色主题）
```

## 2. 设计原则（v1.2 核心调整）

**地图是第一展示对象**：所有含地图的页面（驾驶舱 / 地块管理 / 分析决策四模块）均为
**地图全屏铺底**；一切功能性组件（表格、结果面板、图表面板、图层、图例、行政区选择器）
全部**缩小为图标按钮**分布在地图两侧，**点击后展开完整面板**。

## 4. MapView 能力清单

| 能力 | 说明 |
|---|---|
| 底图 | OpenFreeMap 矢量 + Esri 卫星影像（图层开关） |
| 基础控件 | 导航（指南针）/ 比例尺 / 全屏 / 坐标拾取 |
| 右侧图标栏 | 行政区选择器 / 图层控制 / 图例 —— 点击展开面板 |
| 左侧工具条 | 框选 / 圈选 / 多边形（自动统计）+ 距离 / 面积测量（图标化） |
| 要素交互 | 悬停高亮（feature-state）、选中描边、点击弹窗（定位缩放/查看档案） |
| 行政区选择 | 内嵌 RegionSelector：省→市→县三级联动 + 定位 + 地块过滤 |
| 分析叠加图层 | `cells`（适宜性四级配色格网，点击弹得分/等级）与 `coverage`（可达性覆盖=绿/盲区=红，点击弹最近设施） |

props：`parcels/pois/zones/changes/cells/coverage/buffer/highlightId/center/zoom/autoFit/enableSelection/enablePopup/layout/showRegionSelector/showLayerPanel/showLegend/showScale/showCoords/showSelectionPanel`
emits：`parcel-click / parcel-detail / moveend / map-ready / selection / region-select / region-locate / cells-click / coverage-click`
expose：`flyTo / jumpTo / getMap / clearSelection / ready`

## 5. RegionSelector（行政区选择器）

- 固定在地图**右上角**，图标按钮 → 点击展开面板；
- 省（34 个内置）→ 市 → 县 三级联动下拉（市/县数据来自 SHP 导入）；
- "定位"按钮：请求 `/api/regions/{code}/locate` → 地图飞行定位；
- 选中县域 → 发出 `select` 事件，父页面按 `region_code` 过滤地块。

## 6. 页面明细

| 页面 | 布局 | 图标化组件 |
|---|---|---|
| Dashboard | 地图全屏 + 悬浮指标卡/图表 | 行政区/图层（顶栏内联） |
| 地块管理 | 地图全屏 | 表格（左图标展开）、SHP 导入、详情抽屉 |
| 用地转移矩阵（模块一） | 地图全屏 | 数据准备（期次 SHP 导入/演示基期）+ 矩阵表/面积增减图/变化图斑（左图标） |
| 适宜性评价（模块二） | 地图全屏 | 评价设置（目标/权重滑杆/范围）+ 四级适宜性格网与分布图（左图标） |
| 设施可达性（模块三） | 地图全屏 | 分析设置（设施类型/半径/范围）+ 覆盖率饼图/盲区清单/覆盖专题图（左图标） |
| 三区三线体检（模块四） | 地图全屏 | 体检设置 + 问题台账（占用矩阵/图表/CSV 导出/图上定位，左图标） |
| 报告生成 | 卡片布局（非地图页） | 六章节报告预览 + Markdown 下载 |

> 分析决策四模块共用"范围划定"交互：不限定 / 当前行政区（右上角选择器）/ SHP 导入（`/api/analysis/parse-scope`）/ 手动绘制（地图左侧工具）。

## 7. 设计规范

- 深浅双主题、设计令牌 CSS 变量、12 列栅格、骨架屏/空态/重试、二次确认。
- 用地配色遵循 GB/T 21010-2017 制图惯例（黄系=农业、红橙=建设、绿系=生态、蓝系=水域）。
- 1080P/2K 自适应：<1400px 时驾驶舱收起左右图表面板。
