# 07 启动调试指南

## 1. 快速启动（Demo 模式，无需数据库）

### 终端一：后端

```powershell
cd C:\landvision-project\backend
..\venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

- 打开 http://127.0.0.1:8000/docs 查看/调试全部接口。
- 日志出现 `>>> 运行模式：DEMO` 即成功。

### 终端二：前端

```powershell
cd C:\landvision-project\frontend
npm install      # 首次
npm run dev
```

- 打开 http://127.0.0.1:5173 。
- 前端 `/api` 由 Vite 代理到后端 8000（见 vite.config.js）。

## 2. 切换到真实数据库（POSTGIS 模式）

```powershell
# 1. 建库建表灌数据（pgAdmin 依次执行 database/00 → 01 → 02）
# 2. 配置连接
cd C:\landvision-project\backend
Copy-Item .env.example .env
# 编辑 .env：设置 LANDVISION_DB_URL=postgresql+psycopg2://postgres:postgres@localhost:5432/landvision
# 删除或注释 LANDVISION_DEMO=1（让系统自动探测）

# 3. 重启后端，日志出现 >>> 运行模式：POSTGIS 即成功
```

## 3. 常见启动问题速查

| 现象 | 原因 | 解决 |
|---|---|---|
| 端口被占用 | 之前启动未关闭 | 换端口，或 `netstat -ano \| findstr 8000` 杀进程 |
| 前端 5173 打不开 | npm run dev 未启动 | 看终端是否报错；检查 Vite 是否在 5173 |
| 请求 500 | 后端未启动 | 先启动后端，再看后端终端报错 |
| 请求 404 | 路径拼错 | 对照 docs/05 接口表；Swagger 里点"Try it out" |
| 地图空白 | 底图样式加载失败（网络/墙） | 换 MapView.vue 的 BASE_STYLE 为可用样式 |
| 中文乱码 | 控制台编码 | PowerShell 执行 `chcp 65001`；文件本身是 UTF-8 |

## 4. 调试工具

- **Swagger UI**（后端 /docs）：每个接口的可视化调试台。
- **浏览器 F12 → Network**：查看请求/响应/报错，前端调试主战场。
- **浏览器 F12 → Console**：看 Vue 报错与 Axios 拦截器提示。
- **VS Code 调试**：`launch.json` 可配 Python 调试（uvicorn 加 `--reload` 配合断点）。
