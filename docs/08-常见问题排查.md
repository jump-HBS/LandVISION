# 08 常见问题排查

> 按"后端 / 前端 / 数据库"三类整理。遇到报错先看后端终端与浏览器 F12 Console 的具体信息。

## 一、后端问题

| 症状 | 可能原因 | 排查与解决 |
|---|---|---|
| 启动即报 `PostgreSQL 连接失败` | 未安装数据库 / 连接串错误 | 正常现象：自动降级 Demo 模式，可继续开发；装好库后改 `.env` 重启 |
| `ModuleNotFoundError` | 依赖缺失 | `pip install -r requirements.txt`（用 venv 的 python） |
| 接口返回 500 | 服务层异常 | 看后端终端 traceback；多数是参数格式问题 |
| 接口返回 422 | 参数校验失败 | 对照 Swagger 里参数的格式（如 bbox 必须 `minx,miny,maxx,maxy`） |
| 修改代码不生效 | uvicorn 未加 `--reload` | 加 `--reload` 或手动重启 |
| `RuntimeError: ...` 数据库相关 | 强制 POSTGIS 模式但库不可用 | 检查 `.env` 的 `LANDVISION_DEMO`，置 `1` 或删掉该行 |
| 端口 8000 被占用 | 残留进程 | `netstat -ano \| findstr :8000` → `taskkill /PID <pid> /F` |

## 二、前端问题

| 症状 | 可能原因 | 排查与解决 |
|---|---|---|
| `npm run dev` 报错 | 依赖未装/Node 版本旧 | `npm install`；Node ≥ 18 |
| 页面空白 | JS 报错 | F12 Console 看红字；`npm run build` 看编译错误 |
| 接口 404/代理失败 | 后端未启动 / 代理未配置 | 先启动后端；检查 vite.config.js proxy 目标端口 |
| 地图不显示 | 底图样式加载失败 | Network 里看 style 请求是否 200；替换 MapView BASE_STYLE |
| 地图要素不显示 | 数据未加载 | Network 看 `/api/parcels/geojson` 是否 200；检查后端模式 |
| 图表不渲染 | ECharts 容器无高度 | 容器必须有显式高度（如 `.chart { height: 220px }`） |
| 修改页面不热更新 | Vite 卡住 | 重启 `npm run dev` |
| 生产构建 `dist` 空白 | history 路由未回退 | 用 Nginx `try_files ... /index.html`（见 frontend/nginx.conf） |

## 三、数据库问题

| 症状 | 可能原因 | 排查与解决 |
|---|---|---|
| `CREATE EXTENSION postgis` 失败 | 库还没建 / 未装 PostGIS | 先执行 00 脚本建库；用 Stack Builder 装 PostGIS |
| 执行 SQL 中文乱码 | 客户端编码 | 数据库用 UTF8 建（00 脚本已指定）；pgAdmin 选项设 UTF-8 |
| `ST_AsGeoJSON` 返回 null | 几何为空 | 检查插入数据是否用 `ST_GeomFromText(..., 4326)` |
| 面积明显不对 | 坐标系问题 | 4326 下面积是度²；必须 `ST_Transform(geom, 3857)` 或 `::geography` |
| 空间查询慢 | 无 GiST 索引 | 执行 01 脚本建索引；`EXPLAIN ANALYZE` 验证 |
| 视野查询结果错位 | bbox 坐标系不一致 | bbox 必须是 4326 经纬度，与 geom 一致 |
| `psql: could not connect` | 服务未启动 | Windows 服务管理器启动 postgresql-x64-16 |

## 四、通用排错口诀

1. **看日志**：后端终端 / 浏览器 Console / Network，先定位是哪一层出错。
2. **最小化复现**：先用 Swagger 直接调接口，确定后端 OK，再怀疑前端。
3. **查模式**：确认当前是 DEMO 还是 POSTGIS（GET / 返回 mode 字段）。
4. **重启大法**：改配置后重启后端、改代码后确认 --reload 生效。
