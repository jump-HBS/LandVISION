# 09 企业级升级说明（v1.3）

> 本版本按《项目优化方案》对项目进行了三轮企业级改造。
> 本文档说明：做了什么、怎么验证、以及剩余路线图。

## 0. v1.3 业务调整（按用户意见）

| 需求 | 落地 |
|---|---|
| 国家-省-市-县四级检索 | `中国_县.geojson`（2891 县域）→ `tools/build_regions.py` 转换；Demo 懒加载 / PG 一键入库 |
| 检索显示完整行政区范围 | 定位改为 `fitBounds(bbox)` 视野适配 + 行政区边界高亮图层（图层面板可隐藏） |
| 规划审查范围划定 | 审查范围三选一：当前行政区 / SHP 导入 / 手动绘制 |
| 审查地块四类型管理 | 永久基本农田/生态保护红线/城镇开发边界/其他；手动绘制 + SHP 导入 + 删除 |
| 批量占用审查 | `POST /api/planning/review` 地块×审查要素占用面积矩阵 → 统计表格 + 饼图/堆积柱状图 + 报告集成 |
| 地块查看即定位 | 修复 MapView `flyTo` 坐标配对迭代 BUG，点击"查看"立即飞行定位到地块 |
| 分析决策四模块 | 模块一转移矩阵（两期叠加求交）/ 模块二适宜性评价（格网加权叠加）/ 模块三设施可达性（生活圈覆盖）/ 模块四三区三线体检（台账+CSV 导出+图上定位） |
| 删除变化监测模块 | 遥感变化监测按业务意见整体下线：monitoring 路由/change_detection 服务/监测页面/分屏对比组件/change_records 表（Alembic 0003）/相关文档与工具全部移除 |

## 0.1 v1.2 业务调整（此前）

| 需求 | 落地 |
|---|---|
| 行政区覆盖中国全境 | 新增 `regions` 表 + 内置 34 个省级行政区（DataV 公开数据，含边界几何）；市/县经 SHP 导入 |
| 用地性质 12 大类 | 全面切换为 GB/T 21010-2017 一级类（耕地…其他土地），后端枚举校验 + 前端国标配色 |
| 删除土地评估模块 | 移除 valuation 服务/路由/页面；区位估价模型按业务意见下线 |
| SHP 上传可视化 | 后端 pyshp 解析（坐标系校验 + 字段自动映射 + 地类容错映射）；地块与行政区两个导入接口 |
| 地图优先的界面 | 全部地图页改为地图全屏铺底；表格/图表/图层/图例/行政区全部缩为图标，点击展开 |
| 冗余清理 | 删除 valuation.py / evaluation.py / EvaluationView.vue / 估价配置与字段 |

## 3. 剩余路线图（下一批）

- [ ] JWT 认证 + RBAC（接口/菜单/按钮三级权限）—— 与前端路由守卫联动

- [ ] Repository 模式（业务逻辑与 Demo/PG 数据源彻底解耦）

- [ ] 请求竞态取消（AbortController）+ 前端请求缓存
- [ ] 结构化 JSON 日志 + ELK/Loki 采集
- [ ] 监控告警：Prometheus /metrics + Grafana 面板
- [ ] 数据库备份脚本 + 恢复演练文档
