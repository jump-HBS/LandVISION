## 2. 四张表

### 2.1 parcels 地块表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | SERIAL PK | 自增主键 |
| parcel_code | VARCHAR(50) UNIQUE | 地块编号（A-01…） |
| name | VARCHAR(100) | 地块名称 |

| far_limit | NUMERIC(6,2) | 容积率上限 |
| height_limit | NUMERIC(6,2) | 建筑限高（m） |
| geom | geometry(Polygon,4326) | 地块边界 |
| created_at | TIMESTAMP | 建档时间 |

## 4. 空间索引（必须）

四张业务表几何字段全部建 GiST 索引（regions 为 `idx_regions_geom`）。
**v3.0（迁移 0007）**：结果表与标注表补充 GiST 空间索引 ——
`idx_land_change_patches_geom` / `idx_suitability_grids_geom` / `idx_map_features_geom`，
驾驶舱/报告按范围过滤时执行计划为 **Index Scan**（可通过 `EXPLAIN ANALYZE` 验证）。

## 5. 核心 SQL 速查

```sql
-- 按行政区划代码查地块
SELECT * FROM parcels WHERE region_code = '420111';

-- 视野查询（前端 moveend）
SELECT id, name, ST_AsGeoJSON(geom)
FROM parcels
WHERE geom && ST_MakeEnvelope(114.33, 30.48, 114.36, 30.52, 4326);

-- 叠加分析（三区三线体检）
SELECT pl.name, z.zone_name,
       ST_Area(ST_Intersection(pl.geom, z.geom)::geography) AS overlap_m2
FROM parcels pl
JOIN planning_control z ON ST_Intersects(pl.geom, z.geom);

-- 设施可达性：地块 800m 内 POI
SELECT pl.parcel_code, p.name
FROM parcels pl
JOIN pois p ON ST_DWithin(pl.geom::geography, p.geom::geography, 800);
```
