# 03 目录结构（逐文件职责）

## 根目录

```
landvision-project/
├── README.md                  # 项目总览 + 快速开始
├── 项目实现框架.md             # 实现原理与底层逻辑（必读）
├── 外部工作清单.md             # 项目外需要做的工作（含天地图县域 SHP 下载教程）
├── 项目说明书.docx             # 项目说明书（细化到每个文件的职责说明）
├── 启动项目.bat                 # 一键启动脚本（双击自动启动后端 + 前端，就绪后自动打开浏览器）
├── 停止项目.bat                 # 停止脚本（关闭服务窗口 + 清理 8000/5173 端口残留进程）
├── 项目手册与学习指南.docx      # 原始需求文档（学习指南）
├── tools/
│   ├── generate_seed.py       # 种子数据生成器（业务数据 + 省级行政区，单一数据源）
│   ├── build_regions.py       # 把中国_县.geojson 构建为省市县数据（data/china_regions.json）
│   ├── load_regions_pg.py     # 省市县行政区写入 PostgreSQL
│   ├── reset_pg_password.bat  # 重置 PostgreSQL 密码脚本
│   └── assets/
│       ├── china_provinces.json    # 中国省级行政区 GeoJSON（DataV 公开数据）
│       └── province_children/      # 各省下辖市县 GeoJSON（省级边界定位用）
├── database/                  # 数据库脚本
├── backend/                   # 后端
├── frontend/                  # 前端
├── deploy/                    # 部署
├── docs/                      # 本文档目录
└── venv/                      # Python 虚拟环境（不入库）
```

## database/

| 文件 | 职责 |
|---|---|
| 00_create_database.sql | 建库 + 启用 PostGIS 扩展 |
| 01_init_schema.sql | 四张表（parcels/pois/planning_control/regions）+ GiST 空间索引 + 核心查询示例 |
| 02_seed_data.sql | 业务演示数据（生成器产出，勿手改） |
| 03_regions.sql | 中国省级行政区数据 34 个（生成器产出） |
| 05_cities_counties.json | 全国市/县级行政区数据（build_regions.py 的输入资产） |

## backend/

| 文件/目录 | 职责 |
|---|---|
| requirements.txt | 依赖清单（含 pyshp/python-multipart） |
| .env.example | 环境变量模板（复制为 .env 使用） |
| run.py | 一键启动脚本 |
| Dockerfile | 后端镜像 |
| alembic.ini + migrations/ | 数据库迁移（0001 初始 → 0002 期次字段 → 0003 删除变化监测表 → 0004 v2.0 项目与结果表 → 0005 三线标准代码 → 0006 图斑几何通用化 → 0007 v3.0 结果表 GiST 空间索引） |
| examples/parcel_crud_practice.py | 早期学习练习，独立运行 |
| tests/test_smoke.py | 全链路冒烟测试（20 项：含 SHP/POI 导入、框选删除、四模块接口、严格范围聚合、报告生成） |
| app/main.py | 入口：lifespan 模式探测、中间件、异常处理、路由注册 |
| app/config.py | 配置中心（pydantic-settings） |
| app/database.py | SQLAlchemy 引擎与会话 |
| app/models.py | ORM 模型（四张表） |
| app/schemas.py | Pydantic 模型（含 12 大类用地枚举校验） |
| app/demo_data.py | Demo 数据集（生成器产出：业务数据 + 34 省级行政区） |
| app/errors.py | 统一错误码 + 全局异常处理器 |
| app/middleware.py | 请求ID/安全头/限流/审计中间件 |
| app/routers/ | parcels / pois / analysis / planning / projects / map_features / dashboard / report / regions / system |
| app/services/ | 服务层（见下） |

### app/services/ 详解

| 文件 | 职责 | 底层算法 |
|---|---|---|
| spatial.py | 视野查询 / GeoJSON 序列化 / 地块 CRUD / 框选删除 delete-by-geometry | bbox 相交、米↔度换算 |
| regions.py | 省/市/县查询、GeoJSON、定位、导入 | 层级树 + 几何质心/包围盒 |
| shp_import.py | SHP zip 解析与批量入库（v3.0：地块仅面要素、POI 仅点要素、强制项目关联） | pyshp + 字段映射 + 坐标系校验 |
| planning_check.py | 三区三线体检：审查要素管理 + 批量占用叠加 + 台账 CSV | 面面叠加求交 + 管控规则 |
| analysis.py | 转移矩阵 / 适宜性评价 / 可达性分析（模块一~三，v3.0 适宜性矛盾提示） | 两期叠加求交、格网加权叠加、质心距离判定 |
| report_gen.py | 驾驶舱统筹汇总 + 报告生成（共用数据源，v3.0 严格范围聚合） | 全数据源范围过滤 + 交集面积裁剪 + Markdown 模板 |
