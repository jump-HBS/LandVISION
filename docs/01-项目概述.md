# 01 项目概述

## 1. 项目定位

**LandVISION —— 国土空间数据管理与智能分析可视化平台**，面向国土空间规划与自然资源管理场景的 WebGIS 全栈项目，覆盖：

- **数据管理**：地块 / 兴趣点 / 规划控制区 / 变化图斑 / 行政区划（省·市·县）的存储、查询、编辑与 **SHP 批量导入**；
- **智能分析**：用地变化转移矩阵、土地适宜性评价（多因子加权叠加）、服务设施可达性分析（生活圈覆盖）、
  三区三线合规性批量体检（叠加分析 + 问题台账导出）；
- **可视化**：交互式地图（MapLibre，全屏主视觉）、统计图表（ECharts）、分析报告。

> v1.2：用地性质升级为 GB/T 21010-2017 一级类（12 大类）；行政区划覆盖中国全境省级，
> 支持县域级查找与 SHP 导入；土地评估模块已按业务意见移除。
> v1.3：新增“分析决策”三大模块（转移矩阵 / 适宜性评价 / 设施可达性），
> 规划审查升级为“三区三线合规性批量体检”（问题台账 + CSV 导出 + 图上定位）。

## 2. 业务场景

演示区为**武汉市洪山区**（区划代码 420111，中心 114.340°E, 30.500°N），行政区划数据覆盖全国 34 个省级行政区：

| 场景 | 流程 |
|---|---|
| 规划人员 | 右上角行政区选择器省→市→县查找 → 地图定位 → 查看地块属性与三区三线体检结论 |
| 数据管理员 | 上传 SHP 压缩包 → 后端解析入库 → 地图可视化 |
| 分析人员 | 驾驶舱选定分析范围（行政区任意层级 / SHP 范围）→ 统筹查看范围内用地结构/体检/可达性/转移矩阵 → 一键生成同范围报告 |
| 专题分析 | 导入两期地块算转移矩阵 → 划定范围做适宜性评价 → 按生活圈半径算设施可达性 → 批量体检导出问题台账 |

## 3. 功能清单

| 模块 | 页面 | 后端路由 | 核心能力 |
|---|---|---|---|
| 驾驶舱 | Dashboard | /api/dashboard | **分析范围统筹**（行政区任意层级下钻 / SHP 范围导入）+ 范围内全模块统计与可视化 |
| 地块管理 | 地块管理 | /api/parcels | 分页 / CRUD / 视野查询 / **SHP 导入** |
| 模块一 | 用地转移矩阵 | /api/analysis/transition | 两期叠加求交 → 转移矩阵 + 消失/新增图斑 + 面积增减 |
| 模块二 | 适宜性评价 | /api/analysis/suitability | 格网法多因子加权叠加（建设/耕地两目标）→ 四级适宜性 |
| 模块三 | 设施可达性 | /api/analysis/accessibility | 地块质心 → 设施距离 ≤ 服务半径 → 覆盖率 + 盲区清单 |
| 模块四 | 三区三线体检 | /api/planning | 批量占用叠加 + 问题台账 + **CSV 导出** + 图上定位 |
| 报告 | 报告 | /api/report | **继承驾驶舱分析范围**的六章节综合分析 + Markdown 下载 |
| 行政区划 | （地图内嵌选择器） | /api/regions | 省/市/县查询 / GeoJSON / 定位 / **SHP 导入** |

## 4. 双模式运行

| 模式 | 数据源 | 空间运算 | 适用 |
|---|---|---|---|
| **DEMO**（默认） | 内存数据（demo_data.py：10 地块 + 20 POI + 4 规划区 + 7 变化 + 34 省） | shapely | 学习接口/前端，无需安装数据库 |
| **POSTGIS** | PostgreSQL 16 + PostGIS | ST_* SQL | 真实业务，百万级数据 |

启动时自动探测：数据库能连上 → POSTGIS；连不上 → DEMO（日志明确提示）。

## 5. 技术栈总览

```
后端：Python 3.14 · FastAPI · SQLAlchemy 2.0 · GeoAlchemy2 · Shapely · NumPy · PyShp · Alembic
前端：Vue 3 · Vite · Pinia · Vue Router · Axios · MapLibre GL JS · ECharts · Element Plus
数据库：PostgreSQL 16 + PostGIS 3.x（regions/parcels/pois/planning_control 四表）
部署：Docker · Docker Compose · Nginx
```
